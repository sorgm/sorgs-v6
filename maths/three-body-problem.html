Three Body Problem

Not trying to solve the problem, but trying to simulate movement of multiple bodies in gravitational bound situation and project it onto a screen. See setup below.

Config:

(1e1 to 10e10)
(1 to 100)

Setup

    
Basic idea is to calculate discrete movement periods. At any point in time any object has a known position and speed (3D vectors). Every object has a known mass. Gravitational pull can be calculated from a total mass and weighted position of all other masses - this induces a force, which induces an acceleration, which with fixed time per run enables to calculate new positions and speeds. Repeat.

    
So we need:

    
    
        
  • number_of_objects (n): size of setup
    • 
        
  • objects_masses_kg (m): Array [0:n-1] of objects' masses in kg
    • 
        
  • objects_positions_sim_3d_m (p): Array of 3D vectors of objects' postions in simulation in m
    • 
        
  • objects_velocity_sim_3d_m_per_s (v): [3D,..] in m/s (all in [SI] base units) 
    • 
        
  • objects_other_masses_kg (xm): [kg,..] calculated sum of all other masses per object
    • 
        
  • objects_other_positions_sim_3d_m (xp): [3D,..] calculated center of other masses as average of their positions weighted by mass per object
    • 
        
  • objects_acceleration_sim_3d_m_per_s2 (a): calculated acceleration per object in simulation as 3d vector in meter per second squared per object
    • 
    

    
To display this, we need an observer and a screen. We assume both are fixed in space and have no mass (which is unrealistic as hell). The observer watches the center of screen orthogonally without blinking. This setup is available in simulation and in reality and is represented in the virtual display at this html page. Having this, we can project an object to the screen in simulation resulting in a position in screen's coordinates. This can be shown in virtual screen using same coordinates. (see also Abbildung auf Mattscheibe [de])

    
    
So we need:

    
    
        
  • real_screen_size_xy_m: something like [.20,.15] for 20cm wide and 15cm high - real size of the svg shown on monitor
    • 
        
  • real_screen_distance_m: something like .40 for 40cm between eyes and screen - real distance from monitor
    • 
        
  • real_screen_xy_px: size of the svg screen on monitor
    • 
        
  • screen_center_position_3d_m: position of the svg screen (center) in simulation, the window you're observing the scenario from
    • 
        
  • screen_x_3d_m: calculated vector being equivalent to width in svg screen but in simulation measures (left=0)
    • 
        
  • screen_y_3d_m: calculated vector being equivalent to height in svg screen but in simulation measures (top=0)
    • 
        
  • the latter three define a coordinate system in simulation that is equivalent to the svg screen on this page
    • 
        
  • observer_position_3d_m: calculated position of observer in simulation as focus point for projection
    • 
        
  • objects_virtual_positions_xy_px: projected positions of the objects in fraction of screen vectors
    • 
        
  • objects_virtual_diameter_px: projected diameter of the objects in fraction of screen vectors
    •
